# Человекочитаемые ключи задач — Web-интерфейс

## Где отображается ключ

### Список задач
В списке задач ключ отображается перед названием задачи:

```
[CRM-123] Подготовить договор
```

Ключ визуально выделен (badge-стиль). Рядом с ключом есть кнопка копирования.

### Kanban-доска
На карточке задачи в Kanban ключ отображается в верхней части карточки, над заголовком.

### Карточка задачи
В детальной карточке задачи ключ отображается в секции с мета-информацией:

```
Ключ: CRM-123 [Копировать]
```

### Результаты поиска
При поиске по ключу найденная задача отображается с ключом в результатах.

## Как копировать ключ

При нажатии на кнопку копирования рядом с ключом:
1. Ключ копируется в буфер обмена
2. Показывается toast-уведомление: «Ключ задачи скопирован»

## Как искать по ключу

В поле поиска на странице задач можно ввести ключ в любом регистре:

```text
crm-123
CRM-123
Crm-123
```

Система найдёт задачу по точному совпадению ключа.

## Как настроить prefix проекта

1. Открыть страницу редактирования/создания проекта
2. Найти поле «Код проекта для задач»
3. Ввести желаемый prefix (только латинские буквы и цифры, 2–10 символов)
4. Prefix автоматически приводится к верхнему регистру

Пример:
```
Название проекта: CRM System
Код проекта для задач: CRM
```

Если поле оставить пустым, система сгенерирует код автоматически из названия проекта.

### Валидация
- Нижний регистр → автоматически в верхний
- Недопустимые символы → удаляются
- Длина 2–10 символов
- Первый символ — буква
- Дубликаты не допускаются (ошибка 409)

## Почему старые ключи не меняются при смене prefix

При изменении кода проекта старые ключи задач остаются неизменными, чтобы не ломать ссылки из:
- Комментариев
- Чатов
- Писем
- Commit message
- Документации

Новые задачи в проекте получают новый prefix, но с продолжением нумерации.

Пример:
```
Было: CRM-1, CRM-2, CRM-3
Prefix изменён на WEB
Новые задачи: WEB-4, WEB-5
Старые задачи: CRM-1, CRM-2, CRM-3 (не меняются)
```
