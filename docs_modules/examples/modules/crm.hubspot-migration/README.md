# Модуль «HubSpot Data Migration» для TropaTT CRM

## Текущий статус
Пакет пока является информационной заглушкой. Импорт данных не реализован, не запускается через UI/API/MCP и не изменяет CRM. Не загружайте в него реальные данные.

## Планируемый сценарий
Будущий модуль должен обеспечить безопасный, воспроизводимый и контролируемый перенос данных из HubSpot в TropaTT CRM:
- Контакты (HubSpot Contacts -> TropaTT Contacts/Clients)
- Компании (HubSpot Companies -> TropaTT Companies/Clients)
- Сделки (HubSpot Deals -> TropaTT Deals/Projects)
- Заметки и активности (HubSpot Notes/Calls/Meetings -> TropaTT Activity logs/Comments)

## Ключевые возможности
1. **Предпросмотр (Preflight & Dry-run)**:
   - Анализ объемов входящих данных, обнаружение неизвестных и конфликтующих полей без записи в базу данных CRM.
2. **Идемпотентность и сопоставление (Mapping)**:
   - Хранение оригинального `hubspot_id` для предотвращения дублирования при повторных запусках.
   - Дедупликация контактов по email и компаний по ИНН/домену.
3. **Чанкованный импорт (Chunked batching & Checkpoint)**:
   - Импорт порциями по 25-100 записей со сбросом прогресса и возобновлением при таймаутах веб-сервера.
4. **Аудит и откат (Rollback)**:
   - Журнал всех импортированных идентификаторов, позволяющий при необходимости откатить последнюю сессию миграции без повреждения исходных записей CRM.
5. **Совместимость с shared-хостингом**:
   - Работает на стандартном PHP 8.1+, MySQL 8.0/MariaDB, не требует очередей, демонов или root-прав.

## MCP
- `hubspot_migration_status`: сообщает, что импорт пока не реализован.
