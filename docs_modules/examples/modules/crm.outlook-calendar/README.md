# Модуль «Microsoft Outlook Calendar Integration» для TropaTT CRM

## Назначение
Модуль реализует синхронизацию календарей между TropaTT CRM и Microsoft 365 (Outlook Calendar) с использованием Microsoft Graph API:
- Синхронизация встреч, созвонов и событий
- Двусторонний обмен изменениями (pull/push)
- Обработка отмен, участников (attendees) и часовых поясов
- Идемпотентность по Microsoft Graph `id`

## Ключевые возможности
1. **Microsoft Graph API & Delta Query**:
   - Быстрая инкрементальная синхронизация с использованием курсоров дельты (`deltaLink` / `skipToken`).
2. **Конфликтные политики и статусы**:
   - Корректная обработка обновлений, переносов времени и удалений событий.
3. **Безопасность и хранение секретов**:
   - OAuth 2.0 токены хранятся в зашифрованном виде на уровне рабочего пространства и пользователя.
4. **Совместимость с shared-хостингом**:
   - Фоновое обновление подписок webhook и курсоров через штатный планировщик CRM (cron) без демонов и очередей.

## MCP Инструменты
- `outlook_calendar_status`: Проверка статуса подключения и состояния дельта-синхронизации.
- `outlook_calendar_sync`: Ручной запуск инкрементальной синхронизации.
