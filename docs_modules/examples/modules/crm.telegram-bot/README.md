# Telegram Bot Integration (`crm.telegram-bot`)

Официальный модуль интеграции Telegram-бота для **TropaTT CRM**.

---

## Возможности модуля

- **Автоматический приём клиентских заявок в Intake:** Входящие текстовые сообщения от клиентов автоматически регистрируются в очереди заявок CRM (`intake_items`) с сохранением имени клиента, `@username`, Chat ID и текста обращения.
- **Интерактивные ответы:** Автоматическое приветствие при команде `/start` и подтверждение приёма заявки.
- **Персональные уведомления команды:** Сотрудники могут привязать свой рабочий Telegram-аккаунт с помощью одноразового защищённого кода (`/bind <КОД>`) и получать персональные уведомления о назначенных задачах и новых заявках.
- **Режимы Webhook и Polling:**
  - **Webhook:** Быстрая асинхронная доставка событий Telegram в реальном времени с валидацией подписи через заголовок `X-Telegram-Bot-Api-Secret-Token`.
  - **Polling (getUpdates):** Поддержка работы на shared-хостинге, за NAT или на локальном окружении без публичного HTTPS и «белого» IP.
- **Автообнаружение и импорт из `.env`:** Модуль автоматически считывает `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` и `TELEGRAM_WEBHOOK_SECRET` с возможностью импорта в один клик.
- **Безопасность (Security):** Шифрование токена бота в базе данных (AES-256-GCM), маскирование при передаче на клиент, полная совместимость с AST-аудитом безопасности маркетплейса (cURL-клиент без использования запрещённых функций).

## Быстрый старт

### 1. Создание бота в Telegram
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте подсказкам (укажите название и имя пользователя бота).
3. Скопируйте полученный **Bot Token** (вида `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ`).

### 2. Настройка в TropaTT CRM

#### Вариант А: Через веб-интерфейс модуля
1. В боковом меню CRM или в разделе **Администрирование → Модули → Telegram Bot** нажмите кнопку **«Открыть страницу модуля»** (`index.php?route=module-telegram-bot`).
2. Вставьте скопированный токен в поле **Bot Token**.
3. Нажмите **«Проверить соединение (getMe)»** — система проверит доступность Telegram API и подставит имя бота.
4. Нажмите **«Сохранить настройки»**.
5. Для автоматической доставки сообщений нажмите кнопку **«Установить Webhook в Telegram»** (CRM автоматически зарегистрирует адрес вебхука и секретный токен).

#### Вариант Б: Через переменные окружения (.env)
Добавьте параметры в корень проекта в `.env`:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
TELEGRAM_BOT_USERNAME=@MyCompanyBot
TELEGRAM_WEBHOOK_SECRET=my_custom_secret_key_32chars
```
На странице модуля нажмите появившуюся кнопку **«Импорт из .env»**.

## Привязка сотрудников (/bind)

Чтобы сотрудник получал уведомления в личные сообщения:
1. Сотрудник на странице модуля нажимает кнопку **«Получить мой код привязки»**.
2. Система генерирует 8-значный разовый код (например: `A4B7C9D2`).
3. Сотрудник переходит в Telegram к боту компании и отправляет сообщение:
   ```
   /bind A4B7C9D2
   ```
4. Бот подтверждает привязку:
   `✅ Аккаунт успешно привязан! Теперь вы будете получать персональные уведомления CRM в этот чат.`

## API Маршруты

Все API-маршруты модуля монтируются префиксом `_module/crm.telegram-bot/`:

| Метод | Маршрут | Описание | Auth |
|-------|---------|----------|------|
| `GET` | `_module/crm.telegram-bot/status` | Статус бота, KPI, конфигурация | Да |
| `POST` | `_module/crm.telegram-bot/config` | Сохранение настроек | Да |
| `POST` | `_module/crm.telegram-bot/test-connection` | Проверка связи (Telegram getMe) | Да |
| `POST` | `_module/crm.telegram-bot/set-webhook` | Регистрация Webhook в Telegram | Да |
| `POST` | `_module/crm.telegram-bot/delete-webhook` | Удаление Webhook (режим Polling) | Да |
| `POST` | `_module/crm.telegram-bot/poll` | Ручной сбор обновлений (getUpdates) | Да |
| `POST` | `_module/crm.telegram-bot/send-message` | Отправка тестового сообщения в чат | Да |
| `POST` | `_module/crm.telegram-bot/import-env` | Импорт настроек из `.env` | Да |
| `GET` | `_module/crm.telegram-bot/bindings` | Список привязанных сотрудников | Да |
| `DELETE` | `_module/crm.telegram-bot/bindings/{id}` | Отвязка аккаунта сотрудника | Да |
| `POST` | `_module/crm.telegram-bot/bind-request` | Генерация кода привязки | Да |
| `GET` | `_module/crm.telegram-bot/recent-updates` | Журнал последних событий бота | Да |
| `POST` | `_module/crm.telegram-bot/webhook/{org_id}` | Входящий шлюз вебхука Telegram | Нет (по секретному токену) |
