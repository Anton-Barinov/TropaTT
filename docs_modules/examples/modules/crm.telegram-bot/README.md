# crm.telegram-bot

Официальный Telegram бот для TropaTT CRM.

## Возможности
- Приём входящих клиентских обращений в Intake.
- Персональные уведомления сотрудников после безопасной привязки по одноразовому коду (`/bind <CODE>`).
- Идемпотентная обработка событий Telegram с проверкой `update_id`.
- Проверка секретного токена вебхука (`X-Telegram-Bot-Api-Secret-Token`).
- Поддержка shared-хостинга: периодический polling без фонового демона.
