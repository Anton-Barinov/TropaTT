# Модуль «Paystack African Payments Gateway» для TropaTT CRM

## Назначение
Модуль обеспечивает интеграцию с ведущим африканским платёжным провайдером **Paystack** (by Stripe):
- Поддерживаемые рынки: Нигерия (NGN), Гана (GHS), Южная Африка (ZAR), Кения (KES).
- Методы оплаты: Карты, банковские переводы, USSD, мобильные деньги (M-Pesa, MTN/Vodafone MoMo).
- Валидация криптографических подписей webhook (`x-paystack-signature` HMAC-SHA512).
- Привязка транзакций к клиентам, контрагентам и сделкам CRM.

## Архитектура и безопасность
1. **Безопасность (PCI-DSS compliant)**:
   - CRM не хранит данные карт. Инициализация возвращает одноразовый URL авторизации Paystack Checkout.
2. **Идемпотентность и выверка**:
   - Уникальный `reference` транзакции гарантирует отсутствие повторных списаний.
3. **Аудит**:
   - Полное протоколирование переходов состояний (pending -> success / failed / abandoned).

## Настройка

Для серверных запросов задайте `PAYSTACK_SECRET_KEY` в окружении PHP-FPM/CLI. Используйте тестовый ключ
Paystack для проверки и храните секрет только в менеджере секретов или защищённой конфигурации хостинга.
Не передавайте его в MCP аргументах и не записывайте в логи. Инициализация и проверка транзакции
завершаются ошибкой, если секрет не настроен или ответ API не проходит проверку.
