# crm.client-portal

Сервисный процесс клиентского кабинета TropaTT CRM для заявок, согласований и коммуникации.

## Возможности
- Подача заявок клиентом с автоматическим расчётом сроков SLA первого отклика и решения.
- Разделение сообщений: внутренние заметки команды (`is_client_visible = 0`) и клиентские ответы.
- Согласование смет и результатов работ с проверкой принадлежности клиенту и защитой от повторных действий.
- Поддержка мобильных устройств и стандартных тем оформления.
- Интеграция с инструментами MCP: `portal_list_requests` и `portal_resolve_approval`.

## Рабочая очередь команды

Страница модуля показывает обращения только из активного рабочего пространства. Сотрудник с
правом `client.manage` может фильтровать очередь по теме, категории и статусу, открыть описание
и переписку, отправить клиентский ответ либо сохранить внутреннюю заметку. Видимость сообщения
принудительно проверяется сервером; клиентская сессия не может создавать скрытые заметки.
Обычный клиент видит только свои обращения и сообщения, отмеченные как видимые клиенту.
