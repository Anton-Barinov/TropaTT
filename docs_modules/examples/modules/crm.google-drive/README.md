# Модуль «Интеграция с Google Диском» для TropaTT CRM

## Назначение
Модуль связывает файловое хранилище TropaTT CRM с облаком **Google Drive** (Google Drive API v3):
1. **Совместная работа с документами (Google Docs, Sheets, Slides)**:
   - Привязка нативных документов Google к задачам, сделкам и проектам CRM с сохранением прямых интерактивных ссылок для просмотра и комментирования (`webViewLink`).
2. **Иерархическая структура каталогов**:
   - Автоматическое создание папок клиента и проекта на Google Drive: `TropaTT CRM / Clients / {Client_Name} / Projects / {Project_ID}`.
3. **Управление правами доступа (Drive Permissions API)**:
   - Автоматическая выдача прав на чтение (`reader`) или комментирование (`commenter`) клиентам по их email при отправке коммерческих предложений или отчетов.
4. **Резервное копирование и экспорт**:
   - Возможность автоматической ночной выгрузки дампов CRM в Google Drive.

## Безопасность
- OAuth 2.0 токены доступа и refresh tokens хранятся в зашифрованном виде на уровне рабочего пространства (`workspace_id`).
- Минимально необходимые Google OAuth scopes (`https://www.googleapis.com/auth/drive.file`).
