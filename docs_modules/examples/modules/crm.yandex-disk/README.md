# Яндекс Диск для TropaTT CRM

Модуль подключает один аккаунт Яндекс Диска к активному рабочему пространству CRM, проверяет OAuth-токен и вручную передаёт выбранный файл CRM в приватную папку. Публичные ссылки, автоматическая синхронизация и прокси-обходы не включены.

## Требования

- PHP 8.1+, cURL и OpenSSL.
- Постоянный `APP_KEY` не короче 32 символов. Токен защищён AES-256-GCM с отдельным контекстом шифрования модуля; при отсутствии ключа запись завершается ошибкой.
- OAuth-токен Яндекс Диска с правами чтения информации о диске, создания папок и записи файлов.
- Исходящий HTTPS-доступ к `cloud-api.yandex.net`; адрес передачи, возвращённый API, проверяется по домену, DNS/IP и HTTPS-сертификату и закрепляется на разрешённых публичных IP через cURL.

## Настройка и использование

1. Откройте **Модули → Яндекс Диск** в нужном рабочем пространстве.
2. Введите OAuth-токен и корневой путь, например `/TropaTT_CRM`; сохраните настройки.
3. Нажмите **Проверить подключение**. CRM получает UID и доступный/занятый объём диска.
4. Для ручной передачи файла укажите его `file_public_id` и нажмите **Передать в Яндекс Диск**. CRM повторно проверит доступ к файлу, workspace, карантин и размер до чтения с диска. Файл будет сохранён в подпапке по типу связанной сущности и ID сущности.

## Безопасность и ограничения

- API требует аутентификацию, workspace и соответствующие разрешения на настройки или файлы.
- Передача использует `FileService` для object-level авторизации. Карантинные, изменённые, symlink, недоступные и файлы больше 20 МБ блокируются.
- Поставщик API фиксированный; `href` для загрузки проверяется по HTTPS, допустимому домену и публичным IP. DNS-результат закрепляется в cURL, редиректы отключены, сертификат проверяется.
- Ключи не возвращаются UI и не записываются в логи. Файлы остаются приватными; публичные URL не создаются.
- Каждый объект получает content-addressed путь с SHA-256, загрузка выполняется с `overwrite=false`. Повтор после потерянного ответа принимает уже существующий объект только при совпадении типа, пути, размера и SHA-256; иное содержимое не перезаписывается.
- Авто-загрузка, внешние ссылки, OAuth callback и автоматическое обновление токена пока не поддерживаются. При истечении/отзыве токена замените его в настройках.
