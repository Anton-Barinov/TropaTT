# Яндекс Диск: статус интеграции

Пакет пока является заготовкой. MCP-команды сообщают реальное состояние: соединение не настроено,
загрузка и публикация ссылок недоступны. Они не создают фиктивные записи или URL и не меняют
права доступа файлов. Указывать `make_public` не означает, что файл станет публичным.

Загрузка будет включена только после реализации и проверки полного жизненного цикла: проверка
доступа пользователя к исходному CRM-файлу и его workspace, потоковая отправка без предварительной
буферизации, лимиты размера до чтения, проверка типа/сигнатуры, серверное имя объекта, приватный
доступ по умолчанию, защищённая работа с токеном и подтверждение фактического результата от API
Яндекс.Диска. Обход ограничений расширений и выдача ссылок без явного согласия запрещены.
