# Модуль «Интеграция с Яндекс Диском» для TropaTT CRM

## Назначение
Модуль расширяет файловую подсистему TropaTT CRM возможностями облачного диска Яндекса:
1. **Экономия места на shared-хостинге**:
   - Автоматическая или ручная выгрузка тяжелых файлов задач, проектов и тикетов в облако Яндекс Диска.
2. **Публичные ссылки для клиентов**:
   - Генерация красивых ссылок Яндекс Диска прямо в карточке задачи или проекта.
3. **Резервное копирование CRM (Database & Storage backups)**:
   - Автоматический перенос ежедневных дампов базы данных и архивов CRM в защищенную папку Яндекс Диска.
4. **Фирменный лайфхак загрузки (Bypass upload limits)**:
   - Автоматический механизм двухфазной загрузки: при отправке тяжелых бинарных файлов (архивы .zip/.tar, видео, аудио) файл загружается на диск с безопасным временным расширением `.txt`. Сразу после подтверждения успешной заливки модуль переименовывает файл через API Яндекс Диска (`POST /v1/disk/resources/move`) обратно в оригинальное расширение. Это обходит жесткие лимиты и блокировки API на типы файлов.

## Безопасность
- OAuth токен шифруется штатным ключом CRM и хранится на уровне рабочего пространства (`workspace_id`).
- Секреты не передаются в браузер и не утекают в системные логи.
