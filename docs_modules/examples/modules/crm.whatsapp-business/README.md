# crm.whatsapp-business

Официальная интеграция WhatsApp Business Cloud API для TropaTT CRM.

## Возможности
- Приём сообщений через официальные вебхуки Meta Cloud API.
- Проверка цифровой подписи запроса (`X-Hub-Signature-256`).
- Дедупликация входящих сообщений по `wa_message_id`.
- Автоматическое создание переписки и привязка к сущности Intake.
- Изоляция по организациям.

## Ограничения вебхука
- Принимаются только JSON-запросы до 256 КБ; запрос большего размера отклоняется до декодирования CRM и подпись проверяется по исходным байтам.
- PHP SAPI может разобрать form-urlencoded тело до запуска приложения. Этот формат не поддерживается; на shared-хостинге без настройки PHP нельзя гарантировать лимит SAPI-памяти для такого неподдерживаемого типа запроса.
