# crm.whatsapp-business

Официальная интеграция WhatsApp Business Cloud API для TropaTT CRM.

## Возможности
- Приём сообщений через официальные вебхуки Meta Cloud API.
- Проверка цифровой подписи запроса (`X-Hub-Signature-256`).
- Дедупликация входящих сообщений по `wa_message_id`.
- Автоматическое создание переписки и привязка к сущности Intake.
- Изоляция по организациям.
