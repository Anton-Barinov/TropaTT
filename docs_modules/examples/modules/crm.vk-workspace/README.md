# Интеграция TropaTT CRM с VK WorkSpace

Комплексный экосистемный модуль интеграции TropaTT CRM с корпоративной платформой **VK WorkSpace** (VK Звонки, Календарь, Почта, Диск, Мессенджер VK Teams).

---

## Ключевые возможности

1. **Планирование встреч и автогенерация VK Звонков**:
   - Создание встречи прямо из карточки задачи, проекта или клиента CRM.
   - Автоматическая генерация защищенной комнаты видеоконференции **VK Звонков** без ограничения по времени.
   - Ссылка на звонок сохраняется в событии календаря CRM и карточке сущности.
2. **Синхронизация с Календарем VK WorkSpace (CalDAV/API)**:
   - События встреч автоматически появляются в календаре сотрудников VK WorkSpace и на мобильных устройствах.
   - Поддержка статусов принятия приглашений (RSVP: принятно, отклонено, под вопросом).
3. **Оповещения в корпоративный мессенджер VK Teams**:
   - Автоматическая отправка уведомлений о запланированной встрече и прямой ссылки на созвон в личные сообщения или групповые каналы VK Teams через Bot API.
4. **Интеграция с VK Почтой и VK Диском**:
   - Автоматическая отправка приглашений (`.ics` вложений) через корпоративный почтовый домен VK WorkSpace.
   - Хранение материалов встречи и протоколов в корпоративном облаке VK Диск / VK Cloud.
5. **AI-агенты и MCP Mega-tools**:
   - `vk_workspace_status` — проверка подключения к VK WorkSpace API и валидности сервисного токена.
   - `vk_workspace_schedule_meeting` — планирование созвона агентом с созданием ссылки на видеозвонок и рассылкой участникам.

---

## Архитектура таблиц

- `module_vk_workspace_settings` — настройки API-подключения, токен авторизации VK Teams / WorkSpace, домен организации.
- `module_vk_workspace_meetings` — реестр созданных видеовстреч, ссылки на VK Звонки, связка с `calendar_events`, `projects`, `tasks`, `clients`.
- `module_vk_workspace_participants` — список участников встречи с email и статусами.

---

## API Эндпоинты

- `GET /api/v1/vk-workspace/status` — статус подключения.
- `POST /api/v1/vk-workspace/meetings` — запланировать встречу с созданием ссылки на VK Звонок.
- `GET /api/v1/vk-workspace/meetings` — список встреч.
- `POST /api/v1/vk-workspace/sync` — синхронизация календаря.
