# VK WorkSpace для TropaTT CRM — прототип, функции недоступны

Этот пакет — **нерабочий прототип**. Сейчас он не подключается к VK WorkSpace и не выполняет операции во внешнем сервисе. Установка пакета не означает, что интеграция доступна.

## Текущий статус

- Создание встреч и ссылок на видеоконференции: недоступно.
- Чтение или синхронизация календаря, RSVP: недоступно.
- VK Teams, почта и диск: недоступны.
- Настройки подключения и проверка реального соединения: не реализованы.
- MCP-инструмент планирования встречи: не предоставляется.
- API статуса сообщает `provider_api_unavailable`. Маршрут создания встреч и MCP-инструмент планирования удалены; внутренняя сервисная операция отклоняет вызов с `VK_WORKSPACE_INTEGRATION_UNAVAILABLE`. Никакие внешние запросы, встречи, ссылки или идентификаторы при этом не создаются.

Официальные материалы подтверждают наличие Bot API VK Teams, партнерского API VK WorkSpace и поддержку CalDAV/CardDAV в некоторых тарифах. Они не описывают публичный SaaS-контракт, необходимый этому пакету для создания комнаты видеоконференции или управления календарными событиями с авторизацией от имени организации. Нельзя подменять этот контракт неофициальными внутренними API, веб-интерфейсом или API социальной сети ВКонтакте.

- [Официальная документация VK WorkSpace: тарифы и доступность API/CalDAV](https://biz.mail.ru/docs/saas/ru/tariffs/info)
- [Официальная документация VK WorkSpace: календарный бот VK Teams](https://biz.mail.ru/docs/saas/user-guides/vk-teams/calendar-bot/index.html)
- [Официальная партнерская программа VK WorkSpace и партнерский API](https://www.workspacevk.com/partners/)

Пакет нельзя представлять пользователям как подключаемую или работающую интеграцию. До появления официальной документации на нужные SaaS-методы и способ авторизации интерфейс и API должны оставаться fail-closed.
