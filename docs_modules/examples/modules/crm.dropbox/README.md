# Модуль «Интеграция с Dropbox» для TropaTT CRM

## Назначение
Модуль связывает файлы TropaTT CRM с облачным хранилищем **Dropbox** (Dropbox API v2):
1. **Иерархия папок по проектам и клиентам**:
   - Автоматическое создание аккуратной структуры в Dropbox: `/TropaTT_CRM/Projects/{Project_ID}/` и `/TropaTT_CRM/Tasks/{Task_ID}/`.
2. **Dropbox Shared Links**:
   - Генерация ссылок для скачивания или совместного просмотра документов прямо в карточке задачи/проекта CRM.
3. **Разгрузка локального хранилища**:
   - Перенос тяжелых файлов из каталога `storage/uploads/` в безопасное корпоративное облако Dropbox.
4. **Синхронизация через курсоры (Delta sync)**:
   - Отслеживание внешних изменений в папках Dropbox через эндпоинт `/2/files/list_folder/continue` без постоянного polling.

## Безопасность
- Хранение OAuth 2.0 токенов (refresh token flow) в зашифрованном виде на уровне рабочего пространства (`workspace_id`).
- Секреты и токены изолированы и не попадают в клиентские логи.
