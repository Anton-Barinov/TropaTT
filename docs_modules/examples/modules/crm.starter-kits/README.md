# Модуль «Стартовые комплекты» (crm.starter-kits)

Модуль предоставляет готовые преднастроенные рабочие пространства (Starter Kits) для различных типов команд:
1. **Digital / Маркетинговое агентство** (`kit_agency`): статусы согласований, роли аккаунт-менеджера и дизайнера, шаблоны запуска кампаний и сдачи креативов.
2. **Сервисная компания / Service Desk** (`kit_service_desk`): статусы тикетов (диагностика, ожидание клиента, закрытие), роли инженера и лида поддержки, матрица эскалации инцидентов.
3. **IT-команда / Продуктовая разработка** (`kit_product_dev`): статусы спринта, Kanban/Scrum, роли тимлида и разработчика, чеклист Definition of Done (DoD).

## Особенности архитектуры и жизненного цикла
- **Безопасность и отсутствие деструктивных действий**: применение комплекта никогда не перезаписывает существующие статусы, роли или шаблоны. Перед применением рассчитывается предпросмотр (diff/preview).
- **Идемпотентность**: повторный запуск комплекта в одном рабочем пространстве определяет уже созданные объекты и пропускает их без дублирования.
- **Изоляция по рабочим пространствам (Multi-tenancy)**: все создаваемые сущности привязываются строго к `organization_id` вызывающего пользователя.
- **Поведение при удалении/отключении модуля**:
  - Отключение модуля не удаляет созданные пользователем рабочие процессы, статусы и документы.
  - Журнал применённых комплектов сохраняется в таблице `crm_starter_kits_applied` для аудита.

## REST API
- `GET /api/v1/modules/crm.starter-kits/kits?locale=ru-ru` — список доступных комплектов.
- `GET /api/v1/modules/crm.starter-kits/preview?kit_id=kit_agency` — предпросмотр изменений и конфликтов.
- `POST /api/v1/modules/crm.starter-kits/apply` — применение выбранных компонентов (`{"kit_id": "kit_agency"}`).

## MCP Инструменты
- `starter_kits_list` — получение списка комплектов через MCP.
- `starter_kits_preview` — аудит diff перед применением.
- `starter_kits_apply` — применение через ассистента.
