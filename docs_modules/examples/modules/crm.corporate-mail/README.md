# crm.corporate-mail

Интеграция общих почтовых ящиков для TropaTT CRM.

## Возможности
- Подключение общих ящиков команды по протоколам IMAP/SMTP, MS365 Graph или Gmail API.
- Дедупликация входящих писем по заголовку `Message-ID`.
- Сборка писем в треды по заголовкам `In-Reply-To` и `References`.
- Преобразование входящих писем в обращения Intake.
- Изоляция по организациям.
