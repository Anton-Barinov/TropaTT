# Модуль «Mercado Pago Payments (Brazil)» для TropaTT CRM

## Назначение
Модуль обеспечивает создание платёжных ссылок и приём оплат для клиентов в Бразилии через официальный API Mercado Pago:
- Генерация платёжных ссылок Checkout Pro (включая Pix, Boleto, Cartão de Crédito)
- Валидация криптографических подписей webhook (`x-signature` HMAC-SHA256)
- Автоматическая сверка статусов платежей (approved, pending, rejected, refunded)
- Привязка транзакций к клиентам, контрагентам и проектам TropaTT

## Ключевые возможности
1. **Безопасность транзакций (PCI-DSS compliance)**:
   - CRM не обрабатывает и не сохраняет данные банковских карт (PAN/CVV). Оплата происходит на стороне платёжного шлюза.
2. **Идемпотентность и повторные вебхуки**:
   - Гарантированная защита от двойных списаний и дублирования проводок.
3. **Аудит и история переходов**:
   - Детализированный неизменяемый лог статусов транзакции.
4. **Совместимость с shared-хостингом**:
   - Автоматическая сверка через webhook и фоновый cron-опрос зависших оплат.

## MCP Инструменты
- `mercadopago_create_payment_link`: Формирование платёжной ссылки для клиента.
- `mercadopago_check_payment_status`: Запрос актуального статуса платежа и сверка с базой данных CRM.
