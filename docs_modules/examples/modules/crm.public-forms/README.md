# crm.public-forms

Публичные веб-формы заявок и онлайн-запись на встречу для TropaTT CRM.

## Возможности
- Визуальная настройка полей формы и схемы валидации.
- Публичный рендер формы по слагу `/f/{slug}` с поддержкой встраивания в iframe.
- Защита публичной отправки: honeypot, обязательное согласие, allowlist полей по схеме формы, ограничения размера и частоты, идемпотентный ключ для повторов.
- Изоляция по организациям, отсутствие подмены workspace из браузера.
- Интеграция с MCP через инструмент `forms_list`.

## Ограничения публичной отправки
- Максимальный запрос — 32 КБ; максимум 40 полей схемы и 40 переданных полей.
- Одно значение ограничено 4 КБ, все значения вместе — 16 КБ.
- Разрешены только поля, объявленные в `fields_schema_json`; неизвестные, вложенные и повторяющиеся значения отклоняются.
- Не более пяти сохранённых отправок с одного IP на одну форму за 10 минут. Общий API также применяет свой DB-backed лимитер к POST-запросам.
- Повторная отправка должна передавать стабильный ключ `Idempotency-Key` (или `_idempotency_key` для HTML-формы). Тот же ключ и тот же payload безопасно возвращают прежний результат; тот же ключ с другим содержимым отклоняется.
- Отправка формы использует JSON через `fetch`; API отклоняет остальные типы содержимого и ограничивает прочитанное JSON-тело до 32 КБ до декодирования. PHP SAPI может обрабатывать form-urlencoded тело до запуска приложения, поэтому этот формат намеренно не поддерживается.
