# GitLab Integration

Синхронизация Merge Requests GitLab с задачами TropaTT.

> **Источник и статус:** каталог восстановлен как точная копия опубликованного Marketplace ZIP `crm.gitlab-integration` версии `1.1.0`. Текущие изменения — локальная hardening-работа версии `1.1.1`; они не опубликованы.

## Возможности

- Подключение к GitLab.com или self-managed GitLab.
- Связь «проект GitLab → проект TropaTT».
- Merge Requests → задачи (заголовок, описание, статус, метки → теги, исполнитель).
- Обсуждения MR (notes) → комментарии задачи.
- Входящий webhook (проверка `X-Gitlab-Token`) + cron-опрос как fallback для shared-хостинга без публичного webhook.
- Идемпотентная синхронизация: повторный запуск обновляет задачу, не дублируя её.
- Двусторонняя синхронизация комментариев и смены статуса задачи обратно в MR.

## Безопасность и настройка

- Токен и webhook-секрет хранятся зашифрованными (AES-256-GCM на `APP_SECRET`).
- Входящий webhook проверяет `X-Gitlab-Token` до приёма события.
- Синхронизируются только явно связанные проекты текущего рабочего пространства.
- GitLab.com (`https://gitlab.com/api/v4`) разрешён по умолчанию. Self-managed GitLab разрешается только после того, как администратор CRM добавит точный hostname (например, `git.example.com`) в `allowed_api_hosts` конфигурации модуля. Wildcard, IP-адреса, HTTP, нестандартные порты, credentials, query/fragment и хосты вне списка запрещены.
- Перед сетевым запросом приложение разрешает DNS и отвергает private/reserved адреса; все полученные публичные A/AAAA адреса закрепляются в cURL для предотвращения DNS rebinding. Это работает в PHP на shared-хостинге и не зависит от настроек веб-сервера.
- Legacy connections без однозначно определяемого workspace остаются недоступны (fail-closed); администратор может пересоздать их после обновления.

## Ограничения

- Milestones и ревью-заметки (diff-обсуждения) не импортируются (только обычные notes).
- Для self-managed инстанса требуется публично разрешаемый HTTPS hostname, доступный с PHP-хостинга. Частные сети и локальные инстансы намеренно запрещены.
- При сборке Marketplace ZIP подпись manifest должна быть пересоздана штатным release-процессом после финальной проверки файлов.
