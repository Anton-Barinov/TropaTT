# Модуль crm.drawio — Диаграммы draw.io

Встраивание диаграмм [draw.io](https://www.diagrams.net/) в страницы базы знаний TropaTT.

## Возможности

- Создание, редактирование и удаление диаграмм через полноценный редактор draw.io (client-side iframe `embed.diagrams.net`).
- Хранение диаграмм (XML) в собственной таблице модуля `module_drawio_diagrams`.
- Привязка диаграммы к странице базы знаний по `page_public_id`.
- Просмотр диаграммы в режиме только для чтения.
- Готовый HTML-сниппет `<iframe>` для встраивания диаграммы в страницу базы знаний.
- Отдельные списки диаграмм для каждого активного рабочего пространства.

## Безопасность

- XML диаграммы — пользовательские данные; редактирование выполняется в `sandbox`-iframe.
- Все API-маршруты требуют аутентификацию, право модуля и активное рабочее пространство; чтение, изменение и удаление дополнительно ограничены workspace на уровне SQL.
- Доступ к диаграмме внутри пространства по объектному уровню: владелец (`created_by_user_id`) либо пользователь с правом `module.drawio.manage`; root видит всё.
- Диаграммы из версии 1.0.0 при обновлении относятся к текущему основному workspace, так как старая версия не сохраняла их принадлежность к пространству.
- Сообщения iframe принимаются только от точного origin `https://embed.diagrams.net`; `postMessage` не использует wildcard origin.
- Серверных секретов нет: draw.io загружается клиентски, токены не передаются.

## Права

- `module.drawio.view` — просмотр диаграмм.
- `module.drawio.manage` — создание, изменение и удаление диаграмм.

## Примечание

- Модуль не требует внешних ключей и работает на shared-хостинге (PHP 8.1+ и MySQL).
- XML ограничен размером 2 МБ.
- URL редактора задаётся в исходниках модуля и должен оставаться на доверенном origin `https://embed.diagrams.net`.
