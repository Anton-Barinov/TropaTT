# TropaTT

**TropaTT is an AI-ready CRM and project operations platform for teams that need one place for clients, tasks, projects, communication, planning, analytics, and daily execution.**

TropaTT combines a PHP/MySQL CRM core, a clean web interface, built-in installation flow, project management tools, team communication, AI-assisted planning, and modular extensions. It is designed for companies that want a practical self-hosted CRM system instead of a scattered mix of task trackers, spreadsheets, messengers, and client notes.

## English

### What Is TropaTT?

TropaTT is a modern self-hosted CRM for companies that manage client work, internal execution, projects, tasks, and communication in one operational space.

It helps teams answer practical daily questions:

- What should we do today?
- Which tasks are late, blocked, risky, or overloaded?
- Which clients, projects, and counterparties need attention?
- What should each team member focus on without burning out?
- What is happening across projects, chats, approvals, notifications, and analytics?

TropaTT is built for real business routines: dashboards, task lists, Kanban boards, Gantt planning, calendars, client and counterparty records, team structures, notifications, chats, AI plans, idea analysis, admin controls, and modular business logic.

### Why TropaTT?

Many CRM systems are either too narrow, too heavy, too sales-only, or too disconnected from daily execution. TropaTT focuses on the operational layer where client work actually happens: tasks, projects, communication, planning, responsibility, risk, and follow-through.

TropaTT is suitable for:

- small and medium-sized businesses;
- service companies and agencies;
- project-based teams;
- implementation, installation, consulting, and support businesses;
- teams that need both CRM and task management;
- companies that prefer self-hosted software and MySQL-based deployment.

## Installation

TropaTT includes a web installer for a fresh deployment.

### Requirements

- PHP 8.1 or newer.
- MySQL database.
- Web server capable of running PHP.
- Write access for configuration and storage directories.

### Quick Start

1. Upload the project files to your hosting or server.
2. Point the web root to the project web entry point according to your hosting layout.
3. Open the site in a browser.
4. Follow the installer steps.
5. Enter MySQL connection settings.
6. Create the first administrator account.
7. Complete installation and log in.

The installer creates the required configuration, prepares the MySQL database structure, seeds reference data, and creates the initial administrator account.

### Important

Do not commit or publish real production secrets, `.env` files, local database overrides, runtime storage, logs, backups, uploaded files, or private business data.
