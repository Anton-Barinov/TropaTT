# TropaTT

**TropaTT is a free, self-hosted, open-source, AI-ready CRM and project operations platform for teams that need one place for clients, tasks, projects, communication, planning, analytics, automation, and daily execution.**

TropaTT combines a PHP/MySQL CRM core, a clean web interface, built-in installation flow, project management tools, team communication, workflow automation, webhooks, role-based access control, AI-assisted planning, and modular extensions. It is designed for companies that want a practical self-hosted CRM system instead of a scattered mix of task trackers, spreadsheets, messengers, client notes, calendar tools, and disconnected dashboards.

## English

### What Is TropaTT?

TropaTT is a modern free self-hosted CRM for companies that manage client work, internal execution, projects, tasks, and communication in one operational space. The system is open source and can be deployed on your own server with PHP 8.1+ and MySQL.

It helps teams answer practical daily questions:

- What should we do today?
- Which tasks are late, blocked, risky, or overloaded?
- Which clients, projects, and counterparties need attention?
- What should each team member focus on without burning out?
- What is happening across projects, chats, approvals, notifications, and analytics?

TropaTT is built for real business routines: dashboards, task lists, Kanban boards, Gantt planning, calendars, client and counterparty records, team structures, roles, permissions, notifications, chats, AI plans, idea analysis, approvals, SLA, webhooks, admin controls, and modular business logic.

### Why TropaTT?

Many CRM systems are either too narrow, too heavy, too sales-only, or too disconnected from daily execution. TropaTT focuses on the operational layer where client work actually happens: tasks, projects, communication, planning, responsibility, risk, and follow-through.

TropaTT is suitable for:

- small and medium-sized businesses;
- service companies and agencies;
- project-based teams;
- implementation, installation, consulting, and support businesses;
- teams that need both CRM and task management;
- companies that prefer self-hosted software and MySQL-based deployment;
- organizations that want open-source CRM software without mandatory license fees;
- teams that need automation, webhooks, modules, and API-based integrations.

### What Makes TropaTT Different?

TropaTT is not only a sales pipeline. It is closer to an operating system for client work:

- CRM data is connected to tasks, projects, chats, events, notifications, and analytics.
- Project execution is visible through lists, hierarchy, Kanban, Gantt, calendar, day planning, and week planning.
- AI is embedded into workflows where it can help with summaries, plans, risks, priorities, ideas, and next actions.
- Administration is practical: users, roles, permissions, statuses, priorities, SLA, workflow rules, webhooks, modules, logs, API clients, and AI settings.
- The system is self-hosted, so the company keeps control over deployment, data, storage, and integration strategy.

## Installation

TropaTT includes a web installer for a fresh deployment. The installer is designed for a standard PHP/MySQL hosting or server environment.

### Requirements

- PHP 8.1 or newer.
- MySQL database.
- Web server capable of running PHP.
- Write access for configuration and storage directories.
- A domain or local host configured for the web application.
- Ability to create or use an empty MySQL database.

### Quick Start

1. Upload the project files to your hosting or server.
2. Point the web root to the project web entry point according to your hosting layout.
3. Open the site in a browser.
4. Follow the installer steps.
5. Enter MySQL connection settings.
6. Create the first administrator account.
7. Complete installation and log in.

The installer creates the required configuration, prepares the MySQL database structure, seeds reference data, and creates the initial administrator account.

### Installation FAQ

**Is TropaTT free?**  
Yes. The public project is intended for free self-hosted use.

**Can I deploy it on my own server?**  
Yes. TropaTT is designed for self-hosted deployment with PHP 8.1+ and MySQL.

**Do I need paid services to use it?**  
No. Paid implementation or customization services are optional.

**Does it support MySQL?**  
Yes. MySQL is the primary supported database for installation.

**Does it include AI features?**  
Yes. AI-related features are configurable and can be connected to provider settings in the admin area.

### Important

Do not commit or publish real production secrets, `.env` files, local database overrides, runtime storage, logs, backups, uploaded files, or private business data.
