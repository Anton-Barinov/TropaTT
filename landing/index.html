Open source

TropaTT is an open-source project. Deploy it on your own server — no license purchase required. Paid implementation and customization services are optional.

Simple browser-based installation

TropaTT is designed for straightforward installation on shared hosting, VPS, or local host. Upload the files, create an empty MySQL database, open the site in a browser, and follow the installation wizard.

  • Environment check and MySQL availability
  • Database settings, site URL, and timezone configuration
  • First admin account creation
  • Security key generation
  • Automatic .env configuration
  • MySQL schema, migrations, reference data, and seed data setup
  • Storage directory and install lock files to prevent re-installation

No manual SQL imports, config file editing, or frontend build steps required — the installer handles system setup automatically.

FAQ

Is TropaTT free? Yes, completely. Paid services are separate implementation and customization help.

Can I deploy it on my own server? Yes, on any server with PHP 8.1+ and MySQL.

Does it work on shared hosting? Yes, if the host supports PHP 8.1+, MySQL, and write access for config and storage paths.

Do I need to manually import the database? Usually no — the installer prepares the MySQL schema and seed data automatically.

Do I need paid services to use it? No. Self-hosted use is the standard scenario.
