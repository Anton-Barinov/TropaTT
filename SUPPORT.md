# Support

TropaTT is currently in public preview.

## Questions

Use GitHub Discussions if enabled. If Discussions are not enabled, open a GitHub issue with the `question` or `documentation` context.

## Bugs

Open a GitHub issue and include:

- version or commit;
- deployment type: local, shared hosting, VPS, cloud VM, office/home server;
- PHP version;
- MySQL version;
- web server;
- browser;
- steps to reproduce;
- expected result;
- actual result;
- sanitized logs;
- screenshots if relevant.

## Installation Problems

Use the installation problem template and include:

- hosting type;
- PHP version;
- MySQL version;
- file permissions;
- installer step;
- exact error message;
- sanitized logs.

## Security Reports

Do not open public issues for security vulnerabilities. Use `SECURITY.md`.

## Paid Services

Paid customization, integration, migration, or support may exist as optional services. They are not required to use the open-source project.

No support SLA is promised unless a separate agreement exists.
