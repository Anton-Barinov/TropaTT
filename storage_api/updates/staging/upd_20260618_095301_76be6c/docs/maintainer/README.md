# TropaTT Maintainer Docs

This directory contains the public maintainer notes that help contributors, reviewers, and coding agents understand how TropaTT is released, reviewed, and improved.

These files are intentionally public:

- `release-checklist.md` — release preparation and publication checks.
- `security-review-checklist.md` — security areas to review before sensitive changes.
- `codex-for-oss-application-notes.md` — OSS readiness notes for AI-assisted maintenance.
- `starter-issues.md` — first backlog items for contributors.
- `github-labels.md` — suggested issue and PR labels.

Internal product research, private audit notes, screenshots, test artifacts, local deployment notes, and agent scratch work should stay outside this public directory.
