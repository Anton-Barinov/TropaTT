# GitHub Labels

Suggested labels for TropaTT issues and pull requests.

## Type

- `type: bug` — broken behavior or regression.
- `type: feature` — new user-facing capability.
- `type: docs` — documentation, README, examples, or guides.
- `type: security` — auth, permissions, files, secrets, webhooks, CSRF, rate limits.
- `type: maintenance` — CI, cleanup, refactoring, repository health.
- `type: tests` — test coverage, fixtures, test tooling.

## Area

- `area: installer`
- `area: api`
- `area: web-ui`
- `area: ai`
- `area: chat`
- `area: tasks`
- `area: projects`
- `area: calendar`
- `area: notifications`
- `area: admin`
- `area: docs`

## Priority

- `priority: critical` — security issue, data loss, install blocker, or production outage.
- `priority: high` — important regression or core workflow blocker.
- `priority: medium` — valuable fix or improvement.
- `priority: low` — polish or non-blocking cleanup.

## Status

- `good first issue` — small, well-scoped task for new contributors.
- `help wanted` — useful external contribution.
- `needs reproduction` — needs a minimal reproduction or clearer steps.
- `needs decision` — requires maintainer/product decision.
- `blocked` — cannot proceed until another task or external condition is resolved.
