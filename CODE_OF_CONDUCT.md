# TropaTT Code of Conduct

## Our Pledge

TropaTT is an open source project for people building and improving self-hosted CRM, task management, project management, automation, and AI-assisted work tools. We want this project to be useful, practical, and welcoming for contributors with different backgrounds, experience levels, languages, and working styles.

Everyone participating in the TropaTT community is expected to help keep project spaces respectful, professional, and constructive.

## Expected Behavior

Examples of behavior that helps the project:

- Be respectful when discussing code, design, documentation, security, installation issues, and product decisions.
- Assume good intent, but be clear when something is unsafe, misleading, or technically incorrect.
- Give feedback that is specific, actionable, and focused on the work.
- Welcome questions from new contributors and users testing the public preview.
- Respect maintainers' time and the project scope.
- Avoid sharing private data, credentials, logs with secrets, customer data, or screenshots that expose sensitive information.

## Unacceptable Behavior

Examples of behavior that is not acceptable:

- Harassment, threats, intimidation, or sustained disruption.
- Personal attacks, insults, trolling, or hostile comments.
- Discriminatory language or behavior.
- Publishing someone else's private information without clear permission.
- Sharing secrets, credentials, personal data, or customer data in public issues, discussions, pull requests, or logs.
- Using project spaces for spam, scams, or unrelated promotion.
- Repeatedly ignoring maintainer guidance after being asked to stop.

## Scope

This Code of Conduct applies in all TropaTT project spaces, including GitHub issues, pull requests, discussions, release comments, documentation contributions, and any official communication channels connected to the project.

It also applies when someone represents the TropaTT project in public spaces, for example when discussing the project as a maintainer, contributor, or official project representative.

## Reporting

If you see or experience behavior that violates this Code of Conduct, please report it to the project maintainer.

- For non-sensitive conduct concerns, open a GitHub issue and include enough context for maintainers to understand the situation.
- For sensitive concerns, contact the maintainer privately through the GitHub profile associated with this repository.
- For security-sensitive reports, follow the process in [SECURITY.md](SECURITY.md).

Reports should include relevant links, screenshots, dates, and a short description of what happened when it is safe to share them. Do not include private data or credentials in public reports.

## Enforcement

Maintainers are responsible for clarifying expected behavior and responding to reports in a fair and proportionate way.

Possible maintainer actions include:

- Asking for clarification or de-escalation.
- Editing or removing inappropriate content.
- Closing or locking issues, pull requests, or discussions.
- Giving a private or public warning.
- Temporarily or permanently limiting participation in project spaces.

Enforcement decisions should consider the impact of the behavior, the available context, prior behavior, and the safety of the community.
