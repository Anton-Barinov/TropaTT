# Модуль crm.raycast — Raycast (MCP)

Подключение [Raycast](https://www.raycast.com/) (macOS) к существующему MCP-серверу TropaTT.

Модуль **не дублирует** MCP-сервер, а документирует и валидирует доступ:

- Показывает полный URL MCP-эндпоинта, построенный из текущего домена (работает на любом домене и в подпапке — домен не зашит в код).
- Возвращает статус доступа и требования к авторизации.
- Даёт пошаговую инструкцию по добавлению сервера в Raycast.

## API

- `GET /_module/crm.raycast/config` — URL MCP-эндпоинта (`mcp_url`), маршрут (`mcp_route`), признак авторизации (`auth_required`), имя сервера (`server_name`) и статус (`status`).

## Права

- `module.raycast.view` — просмотр страницы настройки.

## Примечание

- Серверных секретов нет, БД-таблиц не создаёт (`migrations: null`).
- URL эндпоинта строится из текущего запроса (`HTTP_HOST`/`SCRIPT_NAME`), поэтому работает на shared-хостинге и в подпапке.
